# fizzgig.app

The Fizzgig Apps website: home, `/privacy/` and `/terms/`. These are the pages Google's sign-in screen links to. Plain HTML, no build.

Pushing to the main branch deploys to Spaceship (`.github/workflows/deploy.yml`). Secrets: `SPACESHIP_HOST`, `SPACESHIP_PORT`, `SPACESHIP_USER`, `SPACESHIP_SSH_KEY`, `SPACESHIP_SSH_PASSPHRASE`, and `SPACESHIP_FIZZGIG_PATH` (absolute path of fizzgig.app's folder).

Keep the privacy policy in step with what the apps do with accounts.
